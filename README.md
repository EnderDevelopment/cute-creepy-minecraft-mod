# Cute & Creepy Mod

A Minecraft mod that makes baby mobs cuter and adds new baby mobs like cute crabs, mini endermen, and a cute lotus flower. It also adds a Slender black creature with unique behaviors.

## Install

1. Download the latest version of the mod from the [releases page](https://github.com/EnderDevelopment/cute-mobs/releases).
2. Place the downloaded JAR file in the `mods` folder of your Minecraft installation.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Encounter baby mobs and new baby mobs to see them say 'how cute!'
2. Hurt baby mobs to see them say 'poor thing'
3. Attack baby mobs to see them say 'How dare you?' in red
4. Encounter the Slender black creature to see it stalk you
5. Hit the Slender black creature to see it say 'Misclick?', 'Accident?', 'Another misclick?'
6. Kill the Slender black creature to see it say 'You monster' in red and hear a static noise
